# Silver automatic SVG + DWG converter (additive PoC)

## Inputs

- `unsupported_enrichment.jsonl` from the previous recovery workflow.
- Raw files under `03_PROJECTS/03_PROJECTS`.
- Optional ODA File Converter executable for DWG → DXF (must be installed separately).

## Windows setup

```powershell
cd "D:\test silver\silver_auto_converter_v1"
..\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

For SVG only, ODA is not required. For DWG, download/install **ODA File Converter** from https://www.opendesign.com/guestfiles/oda_file_converter . Verify its location (commonly within `C:\Program Files\ODA\...\ODAFileConverter.exe`). The script calls ODA via `subprocess`; it cannot independently decode DWG.

```powershell
python auto_convert.py `
  --enrichment "..\unsupported_recovery_v1\unsupported_enrichment.jsonl" `
  --raw-root "..\03_PROJECTS\03_PROJECTS" `
  --out "..\silver_auto_converted_v1" `
  --oda-path "C:\Program Files\ODA\ODAFileConverter 26.12.0\ODAFileConverter.exe"
```

**Replace the `--oda-path` example with the actual executable path**. Or omit this argument to auto-discover the installed executable. On a machine without ODA, DWG output is `NEEDS_ODA`, not `SUCCESS`.

## Outputs

- `results.jsonl`: per-asset status, exact source, extracted entity statistics, conversion details, and failures.
- `text_chunks.jsonl`: SVG text and DWG TEXT/MTEXT/ATTRIB values.
- `preview_manifest.jsonl`, `previews/*.png`: rendered SVG images, ready for SigLIP2 indexing.
- `converted_dxf/*.dxf`: intermediate copies for CAD indexing; original DWG remains unchanged.
- `summary.json`: summary counts.

Input template, Silver JSONL, raw files, image vector index are never modified. The output folder must not already exist. A `SUCCESS` DWG means DXF conversion + limited parse succeeded; it **does not** mean every CAD feature is semantically recognized. DWG visual previews are not generated by this version. `SVG` with broken XML remains an error and should be re-exported or use an independently verified AI/PDF preview.

## Security and QA

- SVG uses `defusedxml`, refuses external references and keeps CairoSVG `unsafe=False`. Run on trusted data or in a sandbox because complex SVG renderers can consume resources.
- ODA subprocess is timeout-bounded and runs on a temporary **copy** of each DWG. A 9-DWG batch must be audited for conversion fidelity, entity counts and text extraction.
- Index `preview_manifest.jsonl` with the existing `index_previews.py` (check its manifest key compatibility first; adapt only the *new copy*, not original manifests).
- New `text_chunks.jsonl` can be fed to the text embedding pipeline after mapping fields.
- `NEEDS_ODA` and `ERROR` remain explicit until fixed.
